=========================================================================================
                GUÍA DE INSTALACIÓN - Proyecto Programación Web Backend
=========================================================================================

REQUISITOS PREVIOS:
- Node.js instalado (v14 o superior), si no se cuenta con el, ejecutar en terminal:
=========================================================================================
    # Instalacion en Windows (usando Chocolatey):
    choco install nodejs
    # Instalacion en macOS (usando Homebrew):
    brew install node
    # Instalacion en Linux y macOS:
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
    nvm install 20
    nvm use 20
=========================================================================================
- Git instalado, si no se cuenta con el, ejecutar en terminal:
=========================================================================================
    # Instalacion en Windows (usando Chocolatey):
    choco install git
    # Instalacion en macOS (usando Homebrew):
    brew install git
    xcode-select --install
    # Instalacion en Linux Ubuntu/Debian:
    sudo apt update
    sudo apt install git
    # Instalacion en Linux Fedora:
    sudo dnf install git
    # Instalacion en Linux RHEL/CentOS:
    sudo yum install git
    # Instalacion en Arch Linux:
    sudo pacman -S git
    # verificar la Instalacion con:
    git --version
=========================================================================================
- Cuenta en MongoDB Atlas (o crear una durante la Instalacion)
- MongoDB Compass instalado (browser de la base de datos), en caso de no tenerlo, seguir la
  Instalacion en el siguiente enlace:
=========================================================================================
    https://www.mongodb.com/try/download/compass
=========================================================================================
- Postman instalado (manejo de peticiones http) en caso de no tenerlo, seguir la
  Instalacion en el siguiente enlace:
=========================================================================================
    https://www.postman.com/downloads/
=========================================================================================

CONFIGURACION INICIAL:
1. CONTAR CON EL REPOSITORIO CLONADO:
- Ejecutar el siguiente comando en terminal:
=========================================================================================
    git clone https://github.com/SebastianBarreraVargas/ProyectoProgramacionWebBackend.git
=========================================================================================

2. NAVEGAR A LA RUTA DEL PROYECTO
- Ejecutar el siguiente comando en terminal:
=========================================================================================
    cd ProyectoProgramacionWebBackend
=========================================================================================

3. CONFIGURACION AUTOMATICA (OPCIONAL):
Si deseas realizar la configuracion de forma automatica, ejecuta el siguiente script:
=========================================================================================
    # En Linux y macOS:
    bash src/scripts/setup.sh
    # En Windows (usando Git Bash):
    bash src/scripts/setup.sh
=========================================================================================
Este script realizara automaticamente:
- Creacion del archivo .env
- Generacion de certificados SSL
- Instalacion de dependencias (opcional)
- Poblacion de la base de datos con datos de ejemplo (opcional)

NOTA: Si ejecutas el script de configuracion automatica, puedes omitir los pasos 5 y 6. Asegurate de editar el archivo .env con tus credenciales de MongoDB y SECRET.

Si prefieres la configuracion manual, continua con los siguientes pasos:

4. VARIABLES DE ENTORNO:
4.1. Crear el archivo de variables de entorno ".env":
- Copiar el contenido de ".env.example" en un nuevo archivo ".env", para ello, ejecutar en
  la terminal el siguiente comando:
=========================================================================================
    cp .env.example .env
=========================================================================================
4.2. Editar el archivo ".env" con sus credenciales:

4.2.1. Configurar MongoDB:
IMPORTANTE: Cada persona debe crear su propia base de datos.
PASOS:
- Crear una cuenta en MongoDB Atlas en el siguiente link:
=========================================================================================
    https://www.mongodb.com/es/cloud/atlas/register
=========================================================================================
- Crear un nuevo cluster (seleccionar el plan FREE)
- Crear un usuario de base de datos (Database Access)
- Permitir acceso desde cualquier IP (Network Access -> Add IP -> 0.0.0.0/0) (hacer manualmente es un boton azul pequeño en el primer paso luego de crear el usuario)
- Obtener la cadena de conexión:
    * USAR MONGO DB COMPASS
    * Copiar la URI (ejemplo: mongodb+srv://usuario:password@cluster.mongodb.net/)
- Pegar la URI en MONGO_URI del archivo ".env"
- Asegurarse que DB_NAME=WebSurfers en el archivo ".env"
NOTA: La base de datos estará vacía inicialmente. Los modelos y colecciones se crearán 
automáticamente al iniciar el servidor.

4.2.2. Generacion del SECRET:
- Generar un SECRET, como recomendacion usar en terminal el siguiente comando:
=========================================================================================
    node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
=========================================================================================
- Una vez generado el SECRET copiarlo de la terminal a la variable de entorno SECRET
en el archivo ".env"

4.2.3. Configuración de puertos:
- Asegurarse de que los puertos 3000, 8443 y 8444 esten disponibles
- Si alguno de los puertos (3000, 8443, 8444) está ocupado: Cambiar los valores 
  SERVER_PORT, HTTPS_PORT o HTTP2_PORT correspondientes en el archivo .env

5. CERTIFICADOS SSL (DESARROLLO LOCAL):
Generar los certificados con mkcert:
- Instalar mkcert, para ello ejecutar en la terminal el siguiente comando:
=========================================================================================
    # Instalacion de mkcert en macOS y Linux:
    brew install mkcert
    # Instalacion de mkcert en Windows:
    choco install mkcert
=========================================================================================
- Para generar los certificados "localhost.pem" y "localhost-key.pem", ejecutar el 
  siguiente comando en la terminal:
=========================================================================================
    mkcert -install
    mkcert localhost
=========================================================================================

6. DEPENDENCIAS:
Instalar las dependencias necesarias para el funcionamiento del proyecto
- Ejecutar en terminal el siguiente comando:
=========================================================================================
    npm install
=========================================================================================

7. POBLAR LA BASE DE DATOS:
El proyecto incluye un script para poblar tu base de datos con datos de ejemplo y prueba.
Este script importara:
- Roles del sistema (Administrador, Usuario, Profesor)
- Materias academicas (Matematicas, Fisica, Quimica, Biologia, etc.)
- Areas de conocimiento relacionadas con las materias
- Tipos de pregunta (Opcion Multiple, Verdadero/Falso, Respuesta Corta, etc.)
- Clasificaciones de edad (Infantil, Primaria, Secundaria, Universidad, Adultos)
- Usuarios de ejemplo con diferentes roles
- Preguntas de ejemplo con diferentes dificultades y estados
- Relaciones entre preguntas y clasificaciones de edad

Para poblar la base de datos, ejecutar el siguiente comando en terminal:
=========================================================================================
    npx tsx src/scripts/import-db.ts
=========================================================================================

NOTA: Este paso es opcional. Si prefieres comenzar con una base de datos vacia, 
omitelo y las colecciones se crearan automaticamente al iniciar el servidor. Los datos 
de ejemplo son utiles para probar la aplicacion sin necesidad de crear manualmente 
cada elemento.

8. EJECUCION:
Levantar el servidor backend:
- Ejecutar el siguiente comando en terminal:
=========================================================================================
    npm run dev
=========================================================================================

EJEMPLO DE USO:
* ACCESO AL SERVICIO DE CREACION DE UNA PREGUNTA:
- PASOS
1. Levantar y ejecutar el servidor con el siguiente comando:
=========================================================================================
    npm run dev
=========================================================================================
2. Acceder a postman y usar el servicio especificado a continuacion (usando el metodo POST):
=========================================================================================
    POST https://localhost:8444/api/token/send?id_us=693164d69da63db3c677fe0e&username=Garabato&role=693170ff90f140f63829c7d3
=========================================================================================
NOTA: Los valores de id_us, username y role deben ser valores validos tanto de id de usuario, nombre de usuario e id de rol validos existentes en la base de datos, sino no funcionara.
3. Presionar el boton se "Send" en postman para obtener la respuesta.
4. Copiar el valor de "token" de la respuesta obtenida a la peticion, que contara con una forma parecida a la siguiente:
=========================================================================================
    {
        "success": true,
        "message": "Token generado correctamente",
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpZF91cyI6IjY5MzE2NGQ2OWRhNjNkYjNjNjc3ZmUwZSIsInVzZXJuYW1lIjoiR2FyYWJhdG8iLCJyb2xlIjoiNjkzMTcwZmY5MGYxNDBmNjM4MjljN2QzIiwiaWF0IjoxNzY1NTY3NzgzLCJleHAiOjE3NjU1Njg2ODN9.trKJQyQQVmSJtvTScyFPTtoF0gNGXQ8KM4N66oYPmik"
    }
=========================================================================================
5. Acceder a otra pestania de postman y usar el servicio especificado a continuacion (usando el metodo POST):
=========================================================================================
    POST https://localhost:8444/api/question/
=========================================================================================
6. Acceder a la seccion de "Body" en Postman y elegir la opcion "raw" y pegar los valores correspondientes a la pregunta que se pretende crear, debe seguir un formato similar al siguiente:
=========================================================================================
    {
        "statement": "Mencione 3 propiedades de la capa de transporte",
        "score": 67,
        "status": "draft",
        "id_question_type": "693a7d730e15b4ce6249b059",
        "difficulty": "medium"
    }
=========================================================================================
7. Seleccionar la seccion de "Authorization" en Postman y seleccionar la opcion de "Bearer Token".
8. En la entrada de texto asociada a la opcion "Bearer Token", pegar el token generado.
9. Presionar el boton se "Send" en postman para obtener la respuesta.
10. Si los datos del usuario ingresados en el Paso 2. son validos y ademas el id del rol ingresado corresponde al id de administrador se obtendra la siguiente respuesta:
=========================================================================================

        "data": {
            "statement": "Mencione 3 propiedades de la capa de transporte",
            "score": 67,

en caso contrario, se obtendra un error si es otro rol o si el token esta mal dado.

SOLUCIÓN DE PROBLEMAS:
- Si hay error de conexión a MongoDB: Verificar que la IP esté permitida en 
  MongoDB Atlas (Network Access -> Add IP Address -> Allow Access from Anywhere)
- Si no funcionan los certificados SSL: Asegurarse de haber ejecutado 
  "mkcert -install" primero
- Si hay errores de dependencias: Eliminar node_modules y package-lock.json, 
  luego ejecutar "npm install" nuevamente
- Si alguno de los puertos (3000, 8443, 8444) está ocupado: Cambiar los valores 
  SERVER_PORT, HTTPS_PORT o HTTP2_PORT correspondientes en el archivo .env
